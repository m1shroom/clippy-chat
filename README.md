# Clippy Chat

Десктопный чат-бот с легендарным помощником Скрепкой (Clippy). Работает на базе искусственного интеллекта в удобном темном интерфейсе.

---

## 💾 Как скачать и установить

1. Перейдите в раздел **Releases** на этой странице GitHub.
2. Скачайте файл установщика `ClippyChat_Setup.exe`.
3. Запустите его, подтвердите установку и следуйте подсказкам. На рабочем столе появится ярлык для запуска.

---

## Управление

* **Ввод текста:** Пишите в поле внизу. Отправка — на **Enter** или по синей кнопке со стрелочкой.
* **Прикрепление файлов:** Иконка скрепки рядом с полем ввода.
* **Очистить чат:** Кнопка с мусорным ведром в левом верхнем углу стирает всю переписку.
* **Закрытие чата:** Если нажать ЛКМ на крестик или на самого Клиппи, окно чата закрывается, но программа не выключается. Клиппи остается на рабочем столе.
* **Как двигать Клиппи:** Клиппи можно перемещать по экрану **строго через правую кнопку мыши (ПКМ)**. ЛКМ для движения заблокирован, чтобы не было случайных кликов.
* **Вернуть чат назад:** Просто кликните ЛКМ по Клиппи, сидящему на рабочем столе, и окно чата откроется снова.
* **Полный выход:** Кнопка закрытия внутри самого чата или через системный трей (зависит от того, куда вывели полное завершение процесса).
